# Mathematics for AI

A beginner-friendly repository where I document my journey of learning mathematics for Artificial Intelligence from scratch.

This repository contains my notes, practice questions, learning resources, and roadmap as I work through the mathematics needed for AI and Machine Learning. My goal is not only to learn but also to create a free resource that makes these topics easier for others.
